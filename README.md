# Shivraj Sonwane Portfolio

A premium static portfolio for Shivraj Sonwane, positioned as an AI-powered career console for recruiters reviewing fresher roles in Java backend development, QA automation, and software testing.

## Features

- Responsive Shivraj.OS cockpit hero with role switcher and proof console.
- Recruiter quick-scan section for availability, role fit, proof stack, and links.
- Proof-of-work project cards for payment integration, SQL finance tracking, AI job application copilot direction, and QA practice.
- Skill matrix grouped by backend, testing, database, tools, and frontend.
- QA lab section showing test case, bug report, automation, and API testing mindset.
- Timeline for education and learning path.
- Accessible navigation, visible focus states, semantic HTML, SEO metadata, Open Graph metadata, and reduced-motion support.
- No heavy UI libraries or paid APIs. Built with HTML, CSS, and vanilla JavaScript.

## Tech Stack

- HTML5
- CSS3 with custom properties, responsive grids, and glassmorphism UI
- Vanilla JavaScript
- Google Fonts: Space Grotesk, IBM Plex Sans, IBM Plex Mono

## Run Locally

This is a static site. Open `index.html` directly, or run a local server from the project folder.

```bash
npx serve .
```

If Node.js is not available, use any static server or the Live Server extension in VS Code.

## Deployment

### GitHub Pages

1. Push this folder to a GitHub repository.
2. Open repository settings.
3. Go to Pages.
4. Select the main branch and root folder.
5. Save and use the generated GitHub Pages URL.

### Vercel

1. Import the repository in Vercel.
2. Keep the framework preset as Other.
3. Use the project root as the output directory.
4. Deploy.

### Netlify

1. Drag and drop the folder into Netlify Drop, or connect the repository.
2. Leave build command empty.
3. Use the project root as the publish directory.
